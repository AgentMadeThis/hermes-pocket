# Limits and release gates

- Compatible sanitized P2 host candidate, not a turnkey consumer hardware kit.
- No firmware/UI/binary/SDK distribution or corresponding-source certification.
- No physical touch, USB/RF, audible output or real model-quality acceptance is
  established by this package's synthetic transport tests.
- Dedicated unrouted Pocket-only in-process home only. Once armed, the veto is
  unconditional until unload; stop before repurposing the process.
- Same-UID malicious processes, administrators, hostile plugins and deliberate
  core/hook replacement are outside this trusted-profile security boundary.
- Existing Music API has no conditional/atomic revision mutation. Privileged
  concurrent controllers or file writers can race validation and dispatch.
- Seek may resume paused playback; missing observations stay unknown.
- Catalog supports 999 entries, compact UI cache only 26; no bulk transfer.
- Fixed generic source labels must be matched to an operator-owned library;
  personal source names and paths from the demonstration are not distributed.
- No automatic retry of Unknown execution or delivery. Local submission is not
  radio-reception or audio proof. Retain durable replay history.
- Standalone bridge CLI/service, serial dependency locking, operator enrollment,
  hardware provisioning and complete clean-consumer installation remain gaps.
- Independent privacy/source review and exact final hosted CI are later gates;
  preparation here performs no public publication or production mutation.
