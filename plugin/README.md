# Pocket native platform plugin

Entrypoint: register(ctx), registered pre_tool_call veto plus register_platform.
MIT license for first-party Python contributions is in ../LICENSE; copying this
folder alone does not qualify a consumer installation. Read ../docs/INSTALL.md before any activation.

No model tools execute in the dedicated Pocket-only home. Local fixed commands
are application operations, not model tools: /status, /note, configured /location
and explicitly enabled HOME music. No arbitrary shell/URL/RF action is added.
